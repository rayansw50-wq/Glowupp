مشروع GlowUp - النسخة بدون PHP
================================
التقنيات:
HTML + CSS + JavaScript + Supabase (قاعدة بيانات سحابية PostgreSQL)

1) فتح المشروع:
- فكّي ضغط الملف.
- افتحي مجلد GlowUp-JS في Visual Studio Code.
- افتحي index.html بالمتصفح للتجربة الأولية.
- قد تحتاجين إضافة Live Server في VS Code لتشغيل الموقع على localhost؛ هذه الإضافة اختيارية.

2) تجربة الموقع قبل ربط قاعدة البيانات:
- الصفحات والمنتجات والسلة والروتين تعمل ببيانات تجريبية.
- السلة تحفظ المنتجات في المتصفح باستخدام localStorage.
- إرسال الطلب أونلاين لن يعمل قبل ربط Supabase.

3) إنشاء قاعدة البيانات المجانية:
- افتحي https://supabase.com/ وأنشئي حساباً ومشروعاً.
- من لوحة المشروع افتحي SQL Editor ثم New query.
- افتحي database/schema.sql وانسخي محتواه إلى SQL Editor ثم Run.
- من Project Settings > API انسخي Project URL و anon/public key.
- افتحي assets/js/config.js وضعي القيمتين بين علامتي الاقتباس في المكان المخصص.
- لا تضعي service_role key في الموقع أبداً؛ المفتاح العام anon فقط.

4) نشر الموقع:
- أنشئي حساباً في https://www.netlify.com/.
- بعد تجهيز config.js، ارفعي مجلد المشروع (المجلد الذي يحتوي index.html) إلى Netlify عبر صفحة إضافة موقع يدوياً/Deploy manually.
- افتحي رابط الموقع الذي يعطيك إياه Netlify.

ملاحظات:
- قاعدة البيانات تستقبل الطلبات فقط بعد تنفيذ schema.sql وضبط config.js.
- صور المنتجات روابط صور تجريبية من Unsplash وتتطلب اتصال إنترنت، وليست صوراً أصلية للعلامات التجارية.
- الأسعار المعروضة تجريبية بالدينار الليبي وليست أسعار بيع مؤكدة.
- روتين البشرة إرشادي عام وليس تشخيصاً طبياً.
